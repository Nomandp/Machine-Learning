Learn More
Lab 01
Data Preprocessing

Cleaning, missing value handling, categorical binary encoding, and StandardScaler normalization.

No Data Leakage: Target grade (G3) strictly removed from input vectors.
Lab 03
Logistic Regression

Probabilistic binary classification mapping student features to probability via the Sigmoid curve:

P(Y=1) = 1 / (1 + e-z)
Lab 05
Random Forest

Ensemble learning with 100 decision trees and bootstrap aggregation for high accuracy and robust generalization.

Feature Importance: G2, G1 & failures top key drivers.
Lab 10
K-Means Clustering

Unsupervised clustering (k=3 determined via Elbow Method) grouping students into behavioral learning personas.

3 Personas: Achiever, Watchlist, High-Risk.
How the System Works
End-to-End Workflow
1
Student Record Ingestion

Teachers enter academic history, study time, absences, and prior semester exam scores (G1 & G2).

2
Feature Normalization

StandardScaler transforms numeric attributes into Z-scores ensuring equitable feature weighting.

3
Dual-Model ML Inference

Random Forest and Logistic Regression compute calibrated probability of final grade deficiency (< 10/20).

4
Early Warning & Intervention

At-Risk students are auto-enrolled in targeted tutoring, attendance counseling, and mentor sessions.
